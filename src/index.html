📜 วิธีเล่นและกติกา

  • เกมนี้เล่นแบบ "ผลัดกันต่อสู้" (turn-based) เจ้าเลือกท่าก่อน แล้วอสูรจะโต้กลับ
  • 🗡️ โจมตี: สร้างความเสียหายปกติให้อสูร ใช้ได้ไม่จำกัด
  • 🛡️ ป้องกัน: ลดความเสียหายที่จะได้รับในเทิร์นของอสูรถัดไปลงครึ่งหนึ่ง
  • 🔥 ท่าไม้ตาย: สร้างความเสียหายสูงมาก แต่มีจำนวนครั้งจำกัดต่อการต่อสู้หนึ่งครั้ง
  • ชนะ: ลดพลังชีวิตอสูรให้เหลือ 0 ก่อน
  • แพ้: พลังชีวิตของเจ้าลดเหลือ 0 ก่อน
  • กดปุ่ม "เพิ่มระดับความยาก" เพื่อเพิ่มพลังชีวิตและพลังโจมตีของอสูร พร้อมลดจำนวนท่าไม้ตายที่ใช้ได้
  • กดปุ่ม "เริ่มใหม่" เพื่อเริ่มการต่อสู้รอบใหม่ในระดับเดิมได้ทุกเมื่อ
  • ใช้แป้นตัวเลข 1 = โจมตี, 2 = ป้องกัน, 3 = ท่าไม้ตาย แทนการคลิกก็ได้
